🚀 InterviewPrep — All-in-One Interview Preparation Platform

InterviewPrep is a full-stack interview preparation platform designed to help students and job seekers prepare for technical interviews, Online Assessments (OAs), coding rounds, and placement processes — all in one place.

The platform provides company-wise Online Assessment preparation, interview notes, coding resources, mock interviews, quizzes, resume tools, AI assistance, and premium resources with Razorpay payments.

⸻

🎯 Why InterviewPrep?

Preparing for placements often requires students to search across multiple platforms for:

* Company-specific OA questions
* Interview experiences
* Technical notes
* Coding questions
* Aptitude and quiz practice
* Resume preparation
* Interview practice
* Company-wise preparation material

InterviewPrep brings these resources together into a single platform.

⚙️ Getting Started

1. Clone the repository

git clone https://github.com/Gopalx2357/InterviewPrep.git

2. Move into the project

cd InterviewPrep/interview-prep-platform

3. Install frontend dependencies

cd frontend
npm install

4. Install backend dependencies

Open another terminal:

cd backend
npm install

5. Configure Environment Variables

Create .env files based on the provided .env.example files.

Never commit real API keys, database credentials, payment secrets, or other sensitive credentials to GitHub.

6. Start the backend

npm start

7. Start the frontend

cd frontend
npm run dev

The application will then be available through the local development URL shown by Vite.

⸻

🔐 Security

This project uses environment variables for sensitive configuration.

Examples include:

* MongoDB credentials

* Razorpay credentials
